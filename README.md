# 芙芙的狗工具箱 · DogOfFurina Toolbox

纯前端工具箱，支持中文 / EN、多标签筛选、八种主题与电脑端本地 AI。所有工具页集中搜索，多个标签按交集筛选；工具可固定到侧边栏并保存偏好。现有 16 个入口，包含图片 / 视频压缩、视频与 GIF 双向转换、格式转换、MIDI、网盘解析等；社交平台解析接入小渡 GET API，识别视频号、小红书等 19 个平台的分享链接，并可选择接口提供的画质、音轨或图片。

当前正式版本：**26.2.2**。版本格式为「年份.大版本.小版本」，年份使用两位数字。

仓库：https://github.com/DogOfFurina114514/DOFTools

语言选择左侧提供淡色无边框「赞助」入口，弹窗并排展示支付宝和微信收款码，可长按图片或查看原图保存，并通过「点个 Star」打开仓库。工具成功后也会显示赞助提示；「不再提示」在本地保存并同步到其他标签页，关闭自动提示后仍可手动打开。失败或取消的工具不会触发提示，已有弹窗和开屏结束后再显示待处理提醒。

设置中的资源状态区分「未检测」与检测后缺失，断网时显示「离线」，支持手动检测本地资源和检查更新。离线资源更新完成后通过 Toast 提醒，五秒后自动刷新，并提供「取消刷新」按钮；首次保存只通知完成。

## 目录

| 路径             | 用途                                                              |
| ---------------- | ----------------------------------------------------------------- |
| `web/`           | 网页开发源码、依赖清单、构建配置与测试                            |
| `docs/`          | 已构建的网页、完整模型分块、字体与运行时，可直接用于 GitHub Pages |
| `documentation/` | 部署、工具接口、模型实测与视觉参考说明                            |

HTML、JS、CSS 都是网页源码。本项目日常维护 `web/` 中的 TypeScript、React 与样式，Vite 将其构建为 `docs/` 中浏览器能直接运行的 HTML、JS、CSS。后续客户端可以复用同一份网页，本次只包含网页项目。

## 开启 GitHub Pages

在仓库 **Settings → Pages** 选择 **Deploy from a branch → main → /docs** 并保存。

发布后的地址：https://toolbox.owo.lat

网页按 `toolbox.owo.lat` 的根目录部署，BrowserRouter 提供 `/settings`、`/tools?tag=image` 等无井号、无 `.html` 地址，404 回退支持直接打开与刷新子页面。旧 `/category/:id` 链接自动进入对应标签筛选。已有 CNAME 会保留；顶栏在滚动时常驻。

## 本地开发

需要 Node.js 20.19+ 或 22.12+。

```sh
cd web
npm ci
npm run dev
```

开发地址：`http://127.0.0.1:5173`。完整 Qwen 和 Basic Pitch 模型已提交到 `web/public/models/`，克隆后无需额外下载模型。若本地资源缺失或损坏，运行 `npm run model:download`：优先从 `docs/models/` 修复并校验 SHA-256，仓库资源缺失时只从已发布的 GitHub Pages CDN 下载。

```sh
npm test
npm run build
npm run pages:check
npm run preview
```

构建只更新 `docs/`，不会清空 `web/` 中的开发文件。开发目录与发布目录均保存完整模型，三份权重共 42 块，每块最多 20 MiB，词表另分为 10 个最多 2 MiB 的文件。独立 Worker 默认使用共享的 64 路下载池，设置中可选 32 / 64 / 128 路，一段完成立即领取下一段。按 512 KiB 字节范围读取词表、权重和推理运行环境，再按清单顺序提供给运行时；下载进度来自实际接收字节，连接和正文停滞会超时报错，取消或失败会中止其余请求。界面显示启动、显卡检测、连接、运行环境、词表、权重、本地资源读取和初始化阶段。准备运行时不会覆盖模型分块清单；构建直接校验已提交分块，无需未跟踪的原始大权重。

模型资源按 128 KiB 块校验 SHA-256 并保存到 IndexedDB，重新打开助手或浏览器可直接复用。设置提供独立的模型下载与清除按钮，以及「允许离线使用」开关：开启后在后台保存模型以外的全部页面、工具模块、Worker、字体、图片与运行时，显示实际保存进度，完整保存后弹出 Toast。Service Worker 支持断网刷新与直接打开子页面；断网且 AI 模型尚未下载完整时提示无法使用 AI。每次启动或恢复联网检查资源清单，复用内容未变的块，完整保存新版本后再切换离线副本。关闭开关清除网站离线资源，保留模型；清除模型保留网站离线副本。两类资源分别更新代次，阻止旧请求写回。浏览器需支持 Service Worker / IndexedDB，生产站点使用 HTTPS；浏览器主动清理站点存储后需重新保存。网盘解析等依赖外部接口的操作仍需联网。

模型下载、清除和状态仅在电脑端显示；手机保留网站离线设置。通用「下载线程」选项在电脑和手机上均可调整，同时用于离线资源保存与模型下载。

离线首页从构建时生成的带哈希二进制副本下载，再按原始 HTML 校验并保存，避免代理注入或托管平台改写首页造成完整性错误。网站资源下载失败会显示具体文件，不再误报模型失败。网站保存使用最多 2 MiB 的连续范围请求，批量检查本地块并分批并行校验，减少手机上的网络请求、数据库事务和校验等待；每块仍为 128 KiB，保留 SHA-256 校验、断点复用和两类资源独立清除。

网站离线保存优先下载 gzip 压缩分包，每包解压后最多 1 MiB；AI 的 ORT 运行环境优先获得完整压缩覆盖，其余分包按传输收益及 Pages 剩余空间生成。分包解压后验证总大小、SHA-256 和各缓存块哈希，再保存原始资源；模型不参与网站压缩包。浏览器不支持 gzip 解压或分包不存在时回退到原始资源。设置分别显示下载数据量和本地保存量。网站资源首次等待连接最多 120 秒，正文连续 30 秒没有数据才超时；慢速网络降低初始并发，网站保存超时后自动降低并发并重试，保留用户选择的 32 / 64 / 128 线程上限。

工具首次执行先等待共享资源加载器就绪，显示「正在准备工具资源」，取消可立即停止等待。普通工具模块、Worker 与运行环境请求也会对短暂网络失败、408 / 429 / 5xx、超时及响应正文中断进行最多三次下载尝试，间隔 250 / 500 毫秒，超时降低并发。重试只覆盖资源请求，不会重复转换用户文件；永久 HTTP 错误和内容校验失败保留明确失败结果。不支持资源加载器的浏览器继续使用直接加载方式。

离线资源更新按块增量进行：完整复用未变化的文件，并从上一个完整快照中复用内容相同的 128 KiB 块，即使文件名或块的位置变化。复制前验证块大小与 SHA-256，损坏块重新下载；只下载缺失块，压缩包和原始缺失范围选择传输量更小的方式。设置显示已复用本地资源、本次下载量及增量更新进度。更新失败保留旧完整快照，关闭离线使用后未完成的复制或下载不能恢复已清除资源；模型保持独立。

生产网页（包括阿里云备用网址）从 `https://toolbox.owo.lat/` 的 GitHub Pages CDN 获取 Qwen、Basic Pitch 与音频 / AI 运行时；github.io 地址会重定向到这个 CNAME，不请求 GitHub 原站或第三方模型仓库。开发环境使用本地资源。阿里云 ESA 使用 `npm --prefix web run build:esa`，静态资源目录为 `docs`；构建会先主动安装包含开发依赖的锁定版本，不依赖 ESA 在仓库根目录检测 `package.json`，随后移除超出 25 MB 的 WASM 副本，运行时从 Pages CDN 获取，并校验单文件大小、文件数、总大小和模型 SHA-256。详见 [ESA 部署说明](documentation/ALIYUN_ESA.md)。

发布时保留前三次构建的带哈希资源及其依赖，旧页面缓存或尚未关闭的标签页仍能加载音频转换等工具模块；连续构建相同资源不会提前淘汰旧文件。

浏览器检查：`npm run test:e2e`。Windows 安装 Edge 时可先设置 `$env:PLAYWRIGHT_CHANNEL = 'msedge'`。`npm run test:model` 使用真实权重检查 WebGPU，普通浏览器检查跳过此耗时项目。

## 已完成的框架

- 图片、视频、音频、文档、解析、其他六个标签，一个工具可以拥有多个标签；统一控件、字段 schema、工作台、搜索和 AI 读取同一工具注册表。
- 概览显示工具总数与标签数量；所有工具页支持 AND 标签筛选与中文 / English 模糊搜索，可将工具固定到侧边栏。
- 图片压缩、格式转换；视频压缩、格式转换、视频转 GIF、GIF 转视频、音频提取、帧提取；音频格式转换；PDF / DOCX / PPTX / Excel / TXT 文档转换；多张图片转 PDF；ZIP 密码恢复。实际格式、可编辑程度和大小限制见 [工具说明](documentation/TOOLS.md)。
- 视频转 GIF 支持截取起点 / 时长、帧率、最长边与循环设置；GIF 转 MP4 / WebM 保留多帧动画和帧延时，支持缩小尺寸、白色 / 黑色背景，单次播放、无音轨。两项工具复用站内 FFmpeg WASM，在可取消 Worker 中本地处理。
- 图片 / 视频压缩支持手动输入质量、尺寸或码率，也可输入每个文件的目标大小（KiB / MiB）自动计算。图片自动搜索质量并按需缩小尺寸；视频按时长分配码率、预留封装开销，超标时调整后重试。结果显示原始 / 输出大小与实际参数；无法达到目标会明确报错。
- 音频转 MIDI：站内 Basic Pitch 模型在浏览器本地识别旋律与和弦；MIDI 转音频：本地合成为立体声音频，支持速度变化、力度、延音踏板和近似乐器音色。两种转换均支持 MP3、WAV、FLAC、M4A / AAC / ALAC、OGG、Opus、WebM、AIFF 和 WMA；带“音频”标签。
- 网盘链接解析：参照 YunX 的使用方式，仅支持蓝奏云、蓝奏云优享版的免登录小文件分享，可浏览文件夹、获取和复制 ≤100 MiB 文件的直链、导出 JSON。使用内置公益解析服务，分享链接与提取码会发送到 `lz.qaiu.top`；无需网盘账号或配置地址，见 [工具说明](documentation/TOOLS.md#网盘链接解析)。
- 顶栏中文 / EN 切换，所有工具元数据、字段、结果与错误支持双语言。
- 浅色、深色、跟随系统；偏好持久化，切换有平滑过渡。
- 普通主题：默认、Material 3、Fluent Design、液态玻璃。八种主题通过共享 React / CSS 控件自绘下拉菜单、滑块、数字步进、复选框、开关、按钮、进度条和弹窗；支持键盘、触屏和深浅模式。
- 每种普通主题独立保存主题色，可选预设或输入十六进制颜色；液态玻璃支持双色渐变预设及两端自定义颜色，并随深浅模式调整背景亮度。
- 游戏主题：原神、绝区零、终末地、Minecraft；开屏接入真实资源准备进度，避免首屏露出内容。
- 首次设置语言、明暗和主题后逐页教学；设置可重开向导。手机导航、帮助和教学均不包含 AI。
- 页面切换效果、自绘滚动条、触屏适配和键盘操作；响应系统减少动态效果偏好。
- 自绘滚动条跟随页面、侧栏和弹窗动画更新位置；切换页面时清理旧区域，避免滚动条停在页面中间。
- AI 作为普通导航标签页；页内跳转保留模型、输入与附件，关闭后释放 Worker。
- Enter 发送、Shift+Enter 换行、Markdown / GFM 输出、IndexedDB 对话及文件保存；本地记录提示可永久关闭。
- 统一 AI 工具接口：只有文字需求时展示工具卡片，可前往使用；本次附带文件时调用注册工具并返回实际输出文件。

## 本地 AI

使用带视觉编码器的 Qwen3.5-0.8B ONNX 模型，在独立 Worker 中通过 WebGPU 运行。模型资源约 833 MiB，全部随站点发布，无云端推理和 API 密钥。桌面需要支持 WebGPU / shader-f16 的显卡及新版 Chrome 或 Edge；手机不提供 AI。

先前实机检查已验证文字、读图与直接函数调用；统一注册表的真实工具推荐也已显示卡片。新上传文件的完整实机输出检查曾在首个 token 前超时，仍需继续验证。模拟 Worker 的浏览器检查验证界面、参数绑定、执行、下载与持久化，不能代替真实模型检查。
