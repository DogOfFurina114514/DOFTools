普通主题包括默认、Material 3、Fluent Design、液态玻璃；游戏主题包括原神、绝区零、终末地、Minecraft。设置与首次向导复用同一个分组选择器。所有主题的可见控件均由共享 React / CSS 实现；游戏主题采用常规系统无衬线字体，通过背景、布局、色彩、形状与开屏体现各自设计。

Fluent Design 参考 [Fluent 2 的材质](https://fluent2.microsoft.design/material) 与 [形状](https://fluent2.microsoft.design/shapes)：中性底层、4px 控件、8px 卡片、细小的蓝色选中标记。保留微软官方 [Fluent UI React v9](https://react.fluentui.dev/) 的调色板与稳定 FluentProvider，页面使用共享自绘控件，切换主题时保持页内会话状态。

液态玻璃参考 Apple 材质设计，以本地 CSS 渐变构成背景，通透表面、24px 背景模糊、柔和高光和多层阴影构成控件。减少透明度或浏览器不支持模糊时回退为不透明表面。

Minecraft 参考 [官方界面](https://www.minecraft.net/en-us)：方块形状、草地与泥土配色、菜单式像素边框和原创 CSS 地形。开屏用 28 个方块显示实际界面准备进度，完成后覆盖并淡出，页面在淡出结束前保持 inert。采用常规系统字体，不加载像素字体或请求外部字体服务。

游戏官网在本次访问中均可加载页面结构；部分大资源加载较慢，保留了官网开屏参考。此次额外核对了终末地官网真实 CSS：加载页底色 `#141414`，标记与转场色 `#fffa00`；字标从页面宽度约 64.45% 处开始，左侧加载轨沿纵向展开，结束时整屏黄色擦入。站内重新实现这些布局和运动，用 TOOL / BOX 原创字标替换官方游戏字标，移动端改为居中字标与横向进度轨。

原神采用官网元素加载符号与游戏云间门扇的视觉语言；绝区零强化官网 NOW LOADING 的粗重倾斜排版与频道感。所有图形使用本地 CSS / SVG，没有角色图、游戏官网 CDN 或外部字体请求。

## 动态与交互

26.2.6 增强原神手册翻页：页面轮廓逐段弯曲，配合 3D 倾斜、抬升和减速落页；独立 `book-fold` 与 `book-shadow` 浏览器快照层承载本地 SVG 纸张折痕、高光及移动投影，后退时镜像运动。材质覆盖当前内容的可见范围，不拦截输入；过渡结束或取消时移除，减少动态效果时停用。无快照 API 的入场动画也加入移动折痕。此版本未运行截图或浏览器验证。

26.2.5 新增主题切页动画：原神旧纸页绕装订边翻转，浏览器后退时反向翻页；绝区零信号压缩与频道跳切；终末地横向扫描；Minecraft 方块逐行重建。普通主题分别采用淡入、Material 缩放展开、Fluent 滑入和液态玻璃模糊聚焦。侧栏和场景保持原位，只对页面内容做过渡。目标路由预载后使用浏览器局部 View Transition 快照，不支持时使用匹配的入场效果；搜索、标签和同页设置更新不触发切页。设置中的“切页动画”独立保存，响应系统减少动态效果。此版本按用户要求仅制作并构建，未运行测试、截图或额外线上核验。

切换到对应风格或刷新时播放。开屏实际预加载桌面三个路由模块（手机两个，不预加载 AI）、等待字体、下载并解码站内图标，最后等待界面绘制；进度按这六项准备任务的完成比例计量，不是下载字节或模型加载进度。28 格进度按顺序展示已完成的工作，不会提前超过实际加载量。失败时保留未完成进度并提供重新加载。

原神铺路阶段不渲染大门，七元素每完成四格点亮一个；全部就绪后大门出现、双扇打开、白光覆盖，再淡出。绝区零使用 28 个等宽独立块，完成后黄绿切屏。终末地使用进度驱动的黄色轨，完成后黄色覆盖全屏，再以 720 毫秒渐变透明显示页面。

跳过按钮与 Escape 可立即关闭，关闭后恢复焦点与滚动。设置可关闭自动播放、主动重播。系统要求减少动态效果时省略运动并显示短暂静态过渡。

开屏画布从第一帧起保持不透明。已保存的游戏风格在 HTML 解析阶段就显示对应底色遮罩，React 首次挂载时直接接续开屏；加载和完成演出期间主页面隐藏且 inert。最后淡出时才解除页面隐藏，淡出结束前仍保持 inert，确保页面在黄色／白色遮罩下平滑显现。

界面资源随项目部署，浏览网站时不请求游戏 CDN。所有风格都覆盖首页、导航、设置、工具目录、AI 界面和弹窗，支持深浅模式及移动布局。

## 26.2.4 页面与场景

四个游戏主题拥有不同的背景、页面结构和控件，而非只替换颜色。页面使用同一工具注册表和处理流程，保留搜索、多标签 AND 筛选、固定、取消、结果与下载。

| 主题      | 场景                       | 首页与目录                                                             | 工作台与控件                                        |
| --------- | -------------------------- | ---------------------------------------------------------------------- | --------------------------------------------------- |
| 原神      | 云雾、星图与星轨           | 双页冒险手册，左页章节目录、右页工具条目，书脊与纸页层次；手机单页排列 | 金边面板、居中标题、菱形装饰与胶囊按钮              |
| 绝区零    | 网点、唱片、扫描线         | 大标题频道海报，右侧频道，票券工具卡                                   | 粗边框、斜切导航、荧光按钮与票券式结果区            |
| 终末地    | 缓慢变形的等高线与坐标网格 | 工业终端，首页右侧标签；桌面目录左侧筛选栏                             | 桌面输入 / 输出左右分栏，方角控件、黄色标记与定位线 |
| Minecraft | 像素太阳、方块云和分层地形 | 居中制作台与网格物品栏                                                 | 立体像素边框、凹陷输入框和凸起按钮                  |

首页优先显示最多六个固定工具；没有有效固定工具时显示压缩、音频替换、音频转 MIDI 和 GIF 双向转换入口。背景固定在页面底层，不拦截点击；手机按可用宽度调整页面和目录排列。

终末地以 Canvas 采样移动山峰的高度场，通过 marching squares 生成等高线，最高每秒 12 帧、像素比最高 1.5。设置中的动态主题背景开关独立于开屏开关并持久保存；关闭动态或启用系统减少动态效果时保持静态背景，页面隐藏时停止 Canvas 绘制。场景不新增外部请求或第三方游戏图片。
