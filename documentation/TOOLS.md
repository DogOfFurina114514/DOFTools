# 26.2.11 工具说明

工具成功完成后会显示支持开发的赞助弹窗，支付宝与微信并排展示，可长按图片保存，并提供收款码原图及仓库 Star 入口。「不再提示」按钮永久保存当前浏览器的偏好，之后成功运行工具不再自动弹出；语言选择左侧的「赞助」入口保留。失败或取消不会触发赞助提示。

18 个工具入口共用多标签注册表、所有工具页双语搜索及电脑端 AI。多选标签要求全部匹配；图钉可固定到侧边栏并保存到当前浏览器，固定项较多时导航独立滚动、控件保持原有尺寸，绝区零主题的选中边缘与阴影完整显示。“仅联网”（online）表示需要调用外部 API，目前只有网盘链接解析和社交平台解析拥有该标签。社交平台解析接入用户提供的小渡 GET API，可选择画质、音轨和图片。原神书壳固定于可视区域，桌面左右纸页独立滚动；手机为单张连续滚动纸页，菜单将整本书向左滑开，露出右侧书签。点击纸页、再次点击菜单或选择书签可收起导航。当前书签入口会在书本顶部显示同色标记。书签具备织带纹理、缝线和选中抽出效果，固定项与图钉保持尺寸，导航独立滚动。手机可以使用工具，仍不提供聊天 AI。文件压缩、转换和 ZIP 密码恢复只在浏览器内处理；网盘解析将分享链接和提取码发送至内置公益解析服务，社交解析将分享链接发送至小渡 API。

## 批量与追加上传

支持多选的字段会累积添加，取消文件选择保留已有列表；相同名称、大小和修改时间的重复文件只保留一次，可单独移除文件。图片 / 视频压缩、图片 / 视频 / 音频 / 文档转换、视频与 GIF 双向转换、音频与 MIDI 双向转换、音频提取、帧提取和 ZIP 密码恢复均支持批量。处理器按顺序运行，每个文件沿用单文件参数与限制，进度按当前文件映射到整批进度；局部失败列出文件名及原因，成功输出仍可下载。全部失败显示错误，取消立即停止并释放当前 Worker。所有输出重名时添加序号，防止打包覆盖。

图片转换 / 压缩的整批输入最多 100 MiB，文档最多 64 MiB，其他独立批处理最多 256 MiB，单文件原有资源限制仍适用。目标大小按每份文件生效。图片转 PDF 合并所有选择的图片；视频替换音频分别选择一份视频与一份音频。

## 酷狗音乐解密

入口 `/tool/kugou-decrypt`，音频标签，独立钥匙图标。选择 Android / Windows 下载的 `.kge / .kgm / .kgma / .vpr / .kgg`，也接受加密数据使用 `.flac` 或 `.kgg.flac` 等后缀的文件。识别以文件头与加密版本为准，正常音频原样导出。当前实现旧版 v2 / v4（包括 VPR）、v3（概念版 KGE / KGM 密钥槽位 1及旧版兼容候选）与 v5（KGG / KGM）；仅接受能解出有效音频头的候选，未知版本与不匹配的结果明确报错。

v2 / v3 / v4 无需导入密钥；v5 必须提供音频 hash 对应的 ekey：Windows 可上传 `KGMusicV3.db`（明文 SQLite 或支持的 1024 字节页加密库），Android 可上传 `mggkey_multi_process` MMKV 文件，也可上传 / 填写 `{"32位hash":"Base64 ekey"}` JSON。单个 ekey 可直接填写，仅对匹配文件有效。浏览器无法自动读取客户端目录；无法获得对应密钥的 v5 文件不能解密。密钥库中的 hash 会规范为小写，批量为每个文件匹配密钥。

音乐文件总大小最多 256 MiB，密钥文件总大小最多 64 MiB。处理在可取消 Worker 内进行，按原始 FLAC / MP3 / OGG / WAV / M4A / AAC 数据导出，不转码或重新编码；再次上传继续追加，局部失败保留其他输出。旧版直接在 Worker 内查表，无需下载大掩码或使用浏览器 gzip 解压；SQL/WASM 随站点打包。完整保存离线资源后无需外部 API，文件与密钥不上传、不持久保存。算法来源及 MIT 许可见 [第三方说明](third-party/KUGOU-SOURCES.md)。

文件名为 `.flac` 不代表其中一定是 FLAC；实际装有 MP3 时输出 `.mp3`。26.2.11 检查 ID3 后的音频头与 MP3 的 Xing / Info / VBRI 字节数；声明长度大于实际数据时，批次结果注明不完整并提示重新完整下载，现有片段仍可导出。解密不能恢复文件中缺失的音频，未出现长度警告也不等于已验证全部音频内容。

## 图片与视频压缩

入口为 `/tool/image-compress` 和 `/tool/video-compress`。两项工具均提供“手动输入参数”和“按目标大小自动计算”，目标单位为 KiB（1024 字节）或 MiB（1024 KiB），可输入小数。结果显示输入 / 输出大小、体积变化及最终参数。目标模式只在实际输出不超过目标后返回下载文件；目标过小会明确报错，不返回超标文件。手动参数可能让原本很小或已经高度压缩的文件变大，结果会如实提示。

图片支持浏览器可读取的图片，批量总输入最多 100 MiB、单图最多 4000 万像素。输出 JPG / WebP / PNG；JPG 将透明背景填为白色，动图只输出第一帧。手动输入质量 1–100 和最长边像素（0 为原尺寸），始终保持比例且不放大。PNG 不使用有损质量参数。目标大小按每张图片分别生效：先尝试原尺寸或最长边限制内的高质量输出，再搜索可满足目标的 JPG / WebP 质量；最低质量仍超标时继续缩小尺寸。PNG 通过缩小尺寸满足目标。结果逐张显示质量、尺寸和大小；重复输出名自动增加序号区分。每张目标不超过 100 MiB。

视频输入最多 256 MiB，输出 MP4（H.264 / AAC）或 WebM（VP9 / Opus），依赖浏览器 WebCodecs。手动视频码率为 16–100000 kbps，音频码率为 0–320 kbps，0 表示移除音轨。分辨率可选原始 / 1080p / 720p / 480p / 360p，按短边限制、保持比例、不放大，并对齐到偶数像素；最大帧率 0 表示保留原帧率，非零限制不超过输入采样得到的平均帧率。

视频目标模式根据实际时长，预留 6% 与 4096 字节封装开销后分配码率；可选择保留音轨或移除。保留时先检测原生编码器对该音轨声道数 / 采样率支持的音频码率，按实际可用值分配预算，重试仍使用可用码率；AAC 在部分 Windows 浏览器上只支持 96 / 128 / 192 等离散 kbps 值。手动输入不可用音频码率时给出调整提示。输入无音轨时不创建音轨。强制重新编码，避免同格式仅复制原始数据；输出超标会降低码率与尺寸，最多尝试 5 次。保留音轨时若浏览器不能处理该音轨会报错，不静默丢弃。实际结果可能小于目标，每个目标不超过 256 MiB。取消或离开页面会终止视频 Worker；图片处理会在编码步骤之间检查取消并释放画布与本地 URL。

## 视频替换音频

入口 `/tool/video-audio-replace`，标签为视频、音频。分别选择视频和替换音频，输出 MP4（H.264 / AAC）或 WebM（VP8 / Opus）。原视频音轨全部移除，只使用所选音频的首条音轨和视频的首条画面轨；从素材起点对齐，不混合原声。

“截取至视频长度”保留视频时长，音频较长时截断、较短时补静音；“截取至音频长度”保留音频时长，视频较长时截断、较短时延长最后一帧。用户已选择静音 / 末帧补齐方案，不循环素材。结果显示两份素材与所选输出时长，时间可能受视频帧与音频编码帧精度影响。

两份输入总计最多 256 MiB，支持可读取的 MP4、WebM、MOV、MKV、TS、MP3、WAV、M4A、AAC、OGG、Opus、FLAC 等。输出最长 60 分钟；画面最多 8192 × 8192 且不超过 4000 万像素。按显示尺寸输出，必要时对齐偶数像素。Mediabunny 读取各条实际轨道时长，站内 FFmpeg WASM 在独立 Worker 中重编码和封装，不上传文件。单次处理最长 3 分钟；超时可先缩短素材或降低视频分辨率。取消或离开工具页面会立即终止线程。

## 视频与 GIF 双向转换

入口带“视频、图片”标签：`/tool/video-gif` 与 `/tool/gif-video`。两项工具均在可取消的独立 Worker 中通过站内 FFmpeg WASM 处理，不上传文件，不依赖浏览器原生视频编码器；首次使用按需加载约 31 MiB 的运行时。输入最多 128 MiB，输出最长边 64–1280 像素，保持比例且不放大。GIF 转视频将尺寸补齐到偶数像素，透明区域和补齐区域填为所选白色或黑色；输出无音轨。

视频转 GIF 接受 FFmpeg 可解码的 MP4、WebM、MOV、MKV 等视频。开始时间 0–86400 秒，片段时长 0.1–30 秒（默认 5 秒），到达结尾自动结束；开始时间超过视频时长会报错。输入画面最多 8192 × 8192 且不超过 4000 万像素。帧率 1–30 fps（默认 10），最长边默认 480 像素；可无限循环或播放一次。先按片段分析调色板，再编码动画，避免为调色板保留全部未压缩帧；GIF 的 256 色和百分之一秒延时精度可能造成颜色及时间舍入。

GIF 转视频接受 GIF87a / GIF89a，输出 MP4（H.264）或 WebM（VP8）。转换一个完整播放循环，忽略源文件的无限 / 有限循环设置；静态 GIF 也可转换。解码前校验 GIF 块边界、尺寸、帧数和延时：画布最多 4096 × 4096 且不超过 1600 万像素，单次播放最多 60 秒、1800 帧。帧延时按百分之一秒处理；未设置或小于 20 毫秒的延时按常见浏览器行为使用 100 毫秒。视频以 100 fps 表达这些延时，通过重复画面保留每帧（包括最后一帧）的停留时间，无需改变动画节奏。

结果显示尺寸、时长及动画帧数。单个编解码步骤最长 3 分钟；处理超时可缩短片段或降低尺寸。取消或离开工具页面会立即终止 Worker，释放运行时和临时文件。

## 音频与 MIDI

两个入口带“音频”标签：`/tool/audio-midi` 与 `/tool/midi-audio`。输入和输出均覆盖 MP3、WAV、FLAC、M4A / AAC / ALAC、OGG、Opus、WebM、AIFF（含 AIF / AIFC 输入）和 WMA。浏览器原生解码失败时由站内单线程 FFmpeg WASM 解码，不要求登录、服务器或跨域隔离；音频始终在本地处理。WAV 直接导出，其他格式按选择实际编码；OGG 使用 Vorbis，Opus 和 WebM 使用 Opus。M4A 默认 AAC，另有无损 ALAC 选项。

有损音频码率可选 96 / 128 / 192 / 256 / 320 kbps，无损输出不使用码率设置。Opus / WebM 固定 48000 Hz，其他格式支持 22050 / 44100 / 48000 Hz；22050 Hz 的 OGG 码率最高 128 kbps。首次使用扩展编解码会按需下载约 31 MiB 的站内运行时，后续由浏览器缓存。取消或离开页面会终止 Worker。编解码运行时及其对应源码说明见 `docs/licenses/FFmpeg-SOURCES.md`。

首次转换先等待共享资源加载器就绪，并显示资源准备状态；模块、Worker 和运行环境请求遇到短暂下载失败会自动重试，无需再次点击处理。重试只重新获取资源，用户文件转换不会重复执行。

音频转 MIDI 使用 Spotify Basic Pitch 1.0.1，模型约 0.9 MiB，生产网页与备用网址均从 GitHub Pages CDN 加载，开发环境从本地加载，不上传音频。Worker 优先使用本地 TensorFlow.js WASM 后端推理，不要求 WebGPU；按批次释放临时张量，退出工具页面或取消会释放线程。输入最多 64 MiB，不限制时长，浏览器原生和 FFmpeg 解码均处理完整音频；支持复音，独奏乐器通常更准确，完整混音、打击乐、噪声与人声可能需要在 MIDI 编辑器中修正。识别灵敏度越高，弱音更容易识别，同时可能出现更多误识别；最短音符可过滤短暂噪声。导出保留识别到的音高、起点、时长和力度，不保留音频的音色，也不生成滑音弯音事件。

MIDI 转音频接受格式 0 / 1，输入最多 8 MiB，不限制时长、音符数或音轨数；格式 2 与 SMPTE 时间格式会明确报错。按原 MIDI 的速度变化、音符时间、力度、音量 / 表情控制、声像、延音踏板及弯音（固定 ±2 半音）合成，打击乐提供近似节奏音色。可选择跟随 MIDI 乐器、钢琴、弦乐或正弦音；音色为本地算法合成，不是 General MIDI 采样音源或原始录音。先合成为 16 位立体声 PCM，再导出所选格式；叠加超出幅度范围时整体衰减，避免削波。

音频与 MIDI 双向转换的编解码不设固定超时，支持随时取消。较长音频和较多音符 / 音轨会增加处理时间及内存使用，实际可处理规模取决于设备与浏览器。

## 网盘链接解析

仅支持蓝奏云和蓝奏云优享版的免登录公开分享。蓝奏云支持 `lanzou*` / `lanzn` 等常用域名，优享版支持 `www.ilanzou.com/s/...`。其他网盘不注册为支持平台，不接收登录账号、Cookie 或 Token。

一次最多 20 个链接、20000 字符；提取码优先使用手动输入，其次使用链接参数，再使用相邻分享文案。单文件分享自动返回名称、大小和下载直链；文件夹分享展示文件列表，点击“获取直链”解析指定文件。支持进入服务返回的子文件夹、返回上级、复制分享信息与直链、重新获取直链。仅提供不超过 100 MiB 的文件下载；超过限制或未返回大小的文件会显示限制提示。需要登录或特殊下载请求头的文件不支持。

点击“开始处理”后，分享链接和提取码会发送到 [Netdisk Fast Download 公益服务](https://lz.qaiu.top)，无需填写服务地址。浏览器请求不携带 Cookie 或认证信息，音频转换仍完全在本地进行。该服务允许浏览器跨域调用，因此无需增加后端，保持 GitHub Pages 的纯前端架构。服务不可用、分享失效或提取码错误时显示错误并允许重试；直链通常有有效期，可重新获取。下载在新标签页打开，实际行为由文件服务器响应头和浏览器决定。

交互参考 [YunX 云析](https://github.com/CYQawa/YunX)；URL 识别、响应校验与前端操作独立实现，未复制其 AGPL-3.0 源码。调用的公益接口来自 [qaiu/netdisk-fast-download](https://github.com/qaiu/netdisk-fast-download)，其服务端源码不包含在本项目中。

使用固定的 GET 接口：

- `/json/parser?url=...&pwd=...`：单文件信息与直链；优享版返回数字目录 ID 时转为获取列表。
- `/v2/getFileList?url=...&pwd=...&dirId=...`：文件夹及子文件夹列表。
- `/v2/getFileDownInfo/{lz|iz}/{param}`：通过列表返回的参数获取文件直链。

一次响应最多 1000 条文件、2 MiB，超时为 30 秒；取消或离开页面会中止请求。验证文件 ID、名称、大小及下载 URL，只允许从固定服务请求已知下载路径。结果可导出为 `share-links.json`，包含 `platform`、`shareId`、`password`、`url`、首次解析得到的 `files` 和逐项 `error`；导出后在预览里新获取的链接不回写既有 JSON 文件。分享链接和 JSON 中会包含提取码。

2026-11-19 已实际检查蓝奏云、优享版的小文件取链与文件夹列表，确认服务允许站点来源的 CORS 请求；常规浏览器测试模拟接口验证错误、大小限制和交互，以免反复占用公益服务。

## 文档保留程度

- PDF 转 Word / PPT 默认为页面图像，扫描页也能保留外观；选择可编辑模式会抽取文字并重新排版，没有 OCR，扫描 PDF 会明确提示不能提取文字。
- Word → PDF 由浏览器排版再绘制页面；PPT → PDF 支持基本文本框、图片、填色和表格，不保证母版、分组变换、艺术字、图表、动画与复杂排版。生成的 PDF 页面为图片，不能搜索或编辑文字。
- Word / PPT 的相互转换重新组织可提取的文字、表格和图片，不保证原始布局。Excel 保留各工作表数据与显示值，分页时按列和行分块；PDF / Word / PPT 输出不重新计算公式。多表 CSV 打包为 ZIP。
- TXT 支持 UTF-8、带 BOM 的 UTF-16，以及 UTF-8 无法解码时的 GB18030。HTML 导出会转义用户文本。PDF / Word / PPT 导出为 XLSX / CSV 时，只将提取内容组织为单元格，不恢复原有表格语义。
- 旧版 DOC / PPT 暂不支持，请先在 Office 中另存为 DOCX / PPTX。

## 浏览器与限制

常规音视频编码和解码依赖浏览器 WebCodecs，建议新版 Chrome 或 Edge；MP3 和 FLAC 编码另有本地 WASM 扩展。GIF 双向转换与 MIDI 的扩展音频编解码使用站内 FFmpeg WASM。需要保留音轨的转换无法处理音轨时会报错。

图片转换和图片 PDF 总输入最多 100 MiB、单图 4000 万像素；图片 PDF 最多 100 张。常规音视频输入最多 256 MiB，GIF 双向转换最多 128 MiB；帧提取最多 100 帧、最长边 1920 像素。文档输入最多 64 MiB、PDF / PPT 最多 100 页；Office 展开内容最多 128 MiB，Excel 最多 10 万单元格、每表 1 万行与 60 列。

ZIP 输入最多 128 MiB、1024 条目、解压后 256 MiB。先通过密码头校验，再完整解压并验证 CRC / AES 认证；随后验证所有文件后输出无密码 ZIP。最多尝试 100 万次，随时可取消。不同条目使用不同密码时不会输出半成品；无法保证恢复强密码，RAR / 7Z 暂不支持。

MP3 的 LAME 库使用 LGPL-2.0-or-later；Mediabunny 与扩展使用 MPL-2.0。对应源码与许可随网页提供，详见根目录 `THIRD_PARTY_LICENSES.md`。
