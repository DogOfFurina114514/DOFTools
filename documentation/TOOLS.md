# 26.0.1 本地工具

八个工具均通过统一注册表进入分类、中文 / EN 搜索和电脑端 AI。手机可以使用工具，仍不提供 AI。文件和密码只在浏览器内处理。

| 分类 | 工具           | 支持范围                                                                                                    |
| ---- | -------------- | ----------------------------------------------------------------------------------------------------------- |
| 图片 | 格式转换       | 浏览器可读取图片 → PNG / JPG / WebP，批量；动图输出第一帧，JPG 白底                                         |
| 视频 | 格式转换       | 可解码的 MP4 / WebM / MOV / MKV 等 → MP4 / WebM，原始或限制分辨率                                           |
| 视频 | 音频提取       | 主音轨 → MP3 / WAV / FLAC / M4A / OGG，可指定起点和时长                                                     |
| 视频 | 帧提取         | 浏览器可播放视频 → PNG / JPG / WebP，按间隔提取，ZIP 内附时间戳 JSON                                        |
| 音频 | 格式转换       | 可解码音频 → MP3 / WAV / FLAC / M4A / OGG                                                                   |
| 文档 | 格式转换       | PDF / DOCX / PPTX 互转；XLS / XLSX / CSV / TXT → PDF / DOCX / PPTX；另提供 XLSX / CSV / TXT / HTML 内容导出 |
| 文档 | 图片转 PDF     | 多张浏览器可读取的图片按选择顺序合并，A4 自动横竖向或匹配图片尺寸                                           |
| 其他 | 压缩包密码恢复 | ZIP 的 ZipCrypto / AES；已知密码、一键常见密码与 1–4 位数字、自定义字典或有限穷举                           |

## 文档保留程度

- PDF 转 Word / PPT 默认为页面图像，扫描页也能保留外观；选择可编辑模式会抽取文字并重新排版，没有 OCR，扫描 PDF 会明确提示不能提取文字。
- Word → PDF 由浏览器排版再绘制页面；PPT → PDF 支持基本文本框、图片、填色和表格，不保证母版、分组变换、艺术字、图表、动画与复杂排版。生成的 PDF 页面为图片，不能搜索或编辑文字。
- Word / PPT 的相互转换重新组织可提取的文字、表格和图片，不保证原始布局。Excel 保留各工作表数据与显示值，分页时按列和行分块；PDF / Word / PPT 输出不重新计算公式。多表 CSV 打包为 ZIP。
- TXT 支持 UTF-8、带 BOM 的 UTF-16，以及 UTF-8 无法解码时的 GB18030。HTML 导出会转义用户文本。PDF / Word / PPT 导出为 XLSX / CSV 时，只将提取内容组织为单元格，不恢复原有表格语义。
- 旧版 DOC / PPT 暂不支持，请先在 Office 中另存为 DOCX / PPTX。

## 浏览器与限制

音视频编码和解码依赖浏览器 WebCodecs，建议新版 Chrome 或 Edge；MP3 和 FLAC 编码另有本地 WASM 扩展。无法保留音轨时转换报错，不静默输出无声视频。

图片转换和图片 PDF 总输入最多 100 MiB、单图 4000 万像素；图片 PDF 最多 100 张。音视频输入最多 256 MiB；帧提取最多 100 帧、最长边 1920 像素。文档输入最多 64 MiB、PDF / PPT 最多 100 页；Office 展开内容最多 128 MiB，Excel 最多 10 万单元格、每表 1 万行与 60 列。

ZIP 输入最多 128 MiB、1024 条目、解压后 256 MiB。先通过密码头校验，再完整解压并验证 CRC / AES 认证；随后验证所有文件后输出无密码 ZIP。最多尝试 100 万次，随时可取消。不同条目使用不同密码时不会输出半成品；无法保证恢复强密码，RAR / 7Z 暂不支持。

MP3 的 LAME 库使用 LGPL-2.0-or-later；Mediabunny 与扩展使用 MPL-2.0。对应源码与许可随网页提供，详见根目录 `THIRD_PARTY_LICENSES.md`。
