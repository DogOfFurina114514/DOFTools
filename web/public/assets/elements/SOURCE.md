# Genshin Impact element symbols

Element artwork belongs to HoYoverse. These game UI symbols are bundled locally for the user-requested Genshin-inspired opening, with no runtime requests to external hosts.

- Pyro / Hydro / Anemo / Electro / Dendro / Geo: https://enka.network/ui/UI_Buff_Element_Fire.png (Water, Wind, Electric, Grass, Rock respectively).
- Cryo: https://static.wikia.nocookie.net/gensin-impact/images/8/88/Element_Cryo.png

Loading-screen order: Pyro, Hydro, Anemo, Electro, Dendro, Cryo, Geo. Symbols use alpha masks to follow the opening palette.
